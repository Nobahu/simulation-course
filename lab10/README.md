# Имитационная модель СМО M/M/N/$${ \infty }$$

Моделирование многоканальной системы массового обслуживания с бесконечной очередью.

## Описание модели

Система реализует СМО M/M/N/$${ \infty }$$ :

- Входящий поток заявок — пуассоновский с интенсивностью **λ**
- Время обслуживания — экспоненциальное с параметром **μ**
- **N** параллельных каналов обслуживания, не ограниченной емкости
- Заявка попадает в очередь, если все **N** каналов заняты

## Параметры запуска

| Параметр | Значение | Описание |
|---|---|---|
| λ | 3 | Интенсивность поступления заявок |
| μ | 2 | Интенсивность обслуживания одного прибора |
| N | 2 | Число параллельных приборов |
| Время моделирования | 100 000 | Условные единицы времени |
| Seed | 503 | Зерно генератора |

| Характеристика | Значение |

| Обслужено заявок | 299687 |
| Всего поступило | 299687 |

| Среднее время в очереди | 0,6511 |

Также по результатам моделирования строится **график распределения числа заявок в системе**. Данные для графика собираются на основе длительности состояний (данного количества заявок).
